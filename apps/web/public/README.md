# Institute logo

Place the original institute PNG here as `hikmah_logo.png`, then rebuild the application. Next.js detects it at build time and displays it in the shared web branding. When the original asset is absent, the interface uses a simple decorative academic mark beside the institute name, without requesting a missing image.

The image supplied in chat was visible as a reference, but its `/Users/.../Downloads/` source path belongs to the user's Mac and was not available in the cloud workspace. The original PNG has not been recreated, altered or replaced with an imitation of the institute logo.
